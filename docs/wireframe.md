# Referensi Wireframe Kopku

## Status
Kelompok sudah memiliki desain Figma. Dokumen ini **hanya mencatat dan memetakan desain yang sudah ada**; tidak membuat desain baru dan tidak mengganti rancangan milik kelompok.

**Tautan Figma:** [Kopku POS — all design](https://www.figma.com/design/JMX0XHg22baBGuoNv5gIRY/Kopku-POS---all-design?node-id=0-1&p=f&t=dVEkT8cJKUEWqHR0-0)

## Pemetaan ke Kebutuhan Milestone 1
| Layar inti | Tujuan | Elemen yang perlu diperiksa pada desain |
|---|---|---|
| Login | Membatasi akses pengguna | Input identitas pengguna, kata sandi, tombol masuk, dan validasi jika dirancang |
| Dashboard | Memberi gambaran kondisi kedai | Ringkasan produk/stok/penjualan dan navigasi utama |
| Daftar produk | Memudahkan melihat data produk | Daftar/tabel, stok, harga, pencarian atau filter bila tersedia |
| Form produk | Input atau perubahan produk | Nama produk, kategori, harga, stok, dan tombol simpan/batal bila tersedia |

Tabel ini merupakan checklist evaluasi, bukan klaim bahwa setiap elemen sudah ada. Periksa frame Figma yang sebenarnya dan sesuaikan bila nama layar atau komponennya berbeda.

## Bukti Desain di Repository
1. Pertahankan file Figma yang sudah dibuat kelompok.
2. Pastikan tautan dapat dibuka oleh dosen dan anggota yang memerlukan akses.
3. Jika diperlukan, simpan screenshot wireframe di `assets/images/wireframes/`.
4. Gunakan nama file jelas seperti `login.png`, `dashboard.png`, `product-list.png`, dan `product-form.png`.
5. Dokumentasi ini tidak mengklaim desain baru dibuat; hanya merapikan dokumentasi dan pemetaan kebutuhan.
